## 本地开发

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m pipeline.export   # 生成 site/data.json
python -m pipeline.export --validate site/data.json   # 发布前独立复核逐标的数据日期
python -m pytest tests/ -v
python -m http.server 8000 --directory site
```

## 收益口径

- **组合收益**：ETF 前复权收盘价（含现金分红），建仓/再平衡均按收盘价成交。
- **费率**：佣金万0.5（0.005%），单笔最低0.5元，ETF免印花税；配置在 `pipeline/fetch.py`。费用总计含建仓交易，已反映在净值里的费用不会再次扣除。
- **再平衡**：每季度（3/6/9/12月）最后交易日收盘，将组合调回 38/28/22/12 目标权重；自 2026-09-30 起，38% 目标分配给当时的策略持仓资产。卖出优先、买入随后，剩余现金保留在组合内。
- **策略成交**：直接读取 510880 策略看板的已成交记录，不重新计算信号。T 日收盘信号在 T+1 交易日开盘执行；轮换使用该 38% 仓位的卖出所得及整手交易留下的仓位现金。季度切换日使用收盘价，之后 510880 使用策略公布的前复权开盘成交价，511260 使用行情源的前复权开盘价；每日收盘估值。上游策略数据日期落后时停止发布。
- **基准**：沪深300、标普500、纳斯达克100均为价格指数收盘点位。每个组合交易日北京时间15:00只使用此前已收盘的对应市场交易日，2026-01-05建仓时的美指基点为2026-01-02收盘。YTD从2025-12-31各指数收盘到同一可用截止日。美指按美元计价且不含股息、汇率与ETF跟踪误差；与人民币ETF组合显示的只是参考收益差。基准缺失时组合仍可发布，图表留下空缺并标注来源日期及状态，不借用未来或旧价格。
- **历史连续性**：`data/pre-q4-snapshot.json` 保存2026-09-29及以前的净值、份额、现金、旧调仓记录、建仓费用及切换日价格。保留资产和511260后续前复权行情均以9月30日已发布价格接续，不重算旧收益。511260锚点134.804来自本看板原有2026-09-30公开数据文件；只有价格列参与缩放。这个快照无需日常更新；若要更正旧历史，需明确修订快照。
- **长期维护**：如果行情接口返回的历史窗口将来短到不再包含 2026-09-30，构建会报错；届时增大行情请求窗口即可，不需要改动旧净值快照。
- **数据源**：东方财富日K为主（前复权自动含分红），腾讯/新浪为备用；510880 策略信号、成交和收盘价来自其公开看板 JSON。159263 退出后不再依赖实时行情。

## 发布前数据日期校验

- 持仓与策略原始行情必须覆盖境内最近已收盘交易日；切换日之后每个境内交易日的价格和511260开盘价必须齐全。主源陈旧会尝试备用源，仍不合格则不上传、不部署。基准以对应组合日期北京时间15:00为截止点；缺失会降级展示并记录状态，不阻断新持仓净值。
- 159263、161130、161125 按深交所日历，518850、510880、511260 和沪深300 按上交所日历；159263 历史固定核验至 2026-09-30。境内上市的海外 LOF 仍按境内上市交易所的收盘日期。SPX、NDX 按美国股票市场日历。
- 收盘界限为北京时间15:00、纽约时间16:00（官方半日市13:00），使用IANA时区处理夏令时。UTC 21:30、22:30及次日00:00分别对应北京时间05:30、06:30、08:00；510880策略源未更新时后续任务重试。
- 当前离线日历明确覆盖 **2025–2026 年**，含交易所假期、周末和已知特别休市，不采用普通工作日近似；2026 年国庆 10 月 1–7 日休市，9 月 30 日行情在假期内可保持合格，10 月 8 日收盘后必须有当日行情。
- **维护要求：进入未配置的交易所本地年份即停止发布**。请在新年首次任务前更新 `pipeline/freshness.py` 中两地官方休市及美国半日市列表，并加入边界测试；遇临时休市也须根据交易所公告更新。不能以延长容忍天数代替日历维护。
- `meta.source_dates` 保留每个必需标的行情日期、基准实际采用日期/预期日期/缺失状态；`updated_at`仅表示生成时间。`stale_after`按下个境内交易日及次日09:00计划补跑期限计算。写文件采用同目录临时文件再原子替换，校验/序列化/替换失败保留旧产物。`health.yml`对外网数据异常产生失败的Actions运行；通知送达取决于现有GitHub通知设置。

## 文件结构

- `pipeline/fetch.py`：行情抓取与多源切换
- `pipeline/freshness.py`：交易所日历与逐标的原始数据日期校验
- `pipeline/portfolio.py`：建仓 + 季度再平衡模拟引擎
- `pipeline/export.py`：统计指标与 `site/data.json` 生成
- `site/`：看板前端（ECharts）
